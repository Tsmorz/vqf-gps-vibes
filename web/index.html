Full-scale ranges. Each sets what the chip can represent before it clips — a clipped sample is thrown away rather than integrated, because all it says is “at least full scale”. Widen one if the traces above flatten against a ceiling during real motion. It is not free: full scale also sets the quantisation step, so ±16 g resolves four times as coarsely as ±4 g and raises the noise floor the filter was tuned against. Changing the accelerometer range makes the filter forget its learned accel bias, which takes a few seconds of GPS to re-learn.

The magnetometer measures the Earth's field plus the board's own. Until it is calibrated that offset distorts the horizontal component heading is derived from, so yaw is noisy while roll and pitch are unaffected. Press Calibrate, then slowly turn the board through every orientation — including upside down, and about all three axes. Watch the implied field strength: keep turning until it stops rising, then press Finish. It should settle near your local field, which is 25–65 µT depending on latitude. Calibrate outdoors if you can — indoors, building steel both weakens and distorts the field, and no calibration can fix a field that changes as the board moves.

Streams every 200 Hz estimator tick — raw IMU, orientation, position, barometer and GPS — over UDP to the computer running task record, which writes a date-stamped file. Leave “send to” blank to record to whatever is showing this page, or give a laptop's address to record there while watching from a phone. Recording carries on if you close this page; stop it here or from the terminal.

Excite the structure the board is attached to — tap it, step the throttle, let go of a deflection — and watch which frequencies keep ringing once the excitation has stopped. The solid traces are the last 1.28 s; the faint ones hold the highest value each bin has reached, so a mode that rang once and faded stays on screen until you clear it. That hold is the reading to take off a ringdown, because by the time you look at the live trace the ring is already gone.

Bins are 0.78 Hz wide and the axis stops at 100 Hz, which is where the IMU's own anti-alias filter stops. Sampling is the estimator's 200 Hz tick, not the 20 Hz telemetry the other panels are drawn from — so nothing here is aliased by the link. Ignore below only moves the dominant readout, not the plot: hand-holding the board puts 1–3 Hz of motion into the accelerometer that would otherwise win every time.

The BMP390 has no built-in altitude — it reports pressure, and height comes from a formula needing a sea-level reference nobody knows. So the filter carries that offset as a state: the barometer supplies fine height detail while GPS anchors the absolute value. Switch it off to see the up channel's ±3σ envelope widen onto GPS altitude alone.

Power GPS + barometer rail

GPS + baro rail—

Cuts the board's switchable regulator (LDO2), which feeds the GPS receiver and the barometer, to save battery when you only need orientation. Position and height then coast on the IMU and drift. Powering back up gives the GPS a cold start, so expect a wait for a fix. The board's status LED shares that rail and goes dark while it is off. Sleep with the BOOT button for the lowest draw of all.

Filter tuning

The two process-noise terms set how fast the 3σ envelope opens between GPS fixes; the measurement sigmas set how hard each fix pulls the estimate back. Changes take effect on the next filter tick — nothing is stored, so a reboot returns to the firmware defaults.
