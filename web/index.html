The magnetometer measures the Earth's field plus the board's own. Until it is calibrated that offset distorts the horizontal component heading is derived from, so yaw is noisy while roll and pitch are unaffected. Press Calibrate, then slowly turn the board through every orientation — including upside down — until it reaches 100 %, and press it again to finish.

Filter tuning

The two process-noise terms set how fast the 3σ envelope opens between GPS fixes; the measurement sigmas set how hard each fix pulls the estimate back. Changes take effect on the next filter tick — nothing is stored, so a reboot returns to the firmware defaults.
